# Icon font

`lichess.woff2` is the icon font of [Lichess](https://github.com/lichess-org/lila/tree/master/public/font), used here for the icons of the chess variants. Lichess is licensed under the [GNU Affero General Public License, version 3 or later](https://www.gnu.org/licenses/agpl-3.0.html); the font collects icons from several sources under their own open licences, which the [Lichess repository](https://github.com/lichess-org/lila#credits) credits.
