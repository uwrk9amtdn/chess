# Stockfish

The two files in this folder are the single-threaded "lite" build of [Stockfish.js](https://github.com/nmrugg/stockfish.js) 19.0.1 by Nathan Rugg, a WebAssembly build of the [Stockfish](https://github.com/official-stockfish/Stockfish) chess engine, taken unchanged from the [`stockfish` package on npm](https://www.npmjs.com/package/stockfish).

They are licensed under the [GNU General Public License, version 3](https://www.gnu.org/licenses/gpl-3.0.html). The source code is in the two repositories linked above.
